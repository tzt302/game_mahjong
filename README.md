# 雀研所 · game_mahjong

一款浏览器内运行的单机日麻训练小游戏。它把真实摸切对局和 AI 牌效分析结合起来，让玩家在每次决策时看到向听数、有效牌种类和剩余进张枚数。

## 当前功能

- 四人麻将和三人麻将牌组
- 普通模式与 AI 教练模式
- 一局战、东风战与半庄战
- 真实牌山、摸牌、弃牌及河牌
- 四家独立牌河与标准万、筒、索、字牌牌面
- 标准四面子一雀头与七对子和牌判定
- 自摸、荣和、立直、两立直、一发、荒牌流局与流局满贯
- 常见一至六番役、役满和双倍役满判定
- 符数、番数、满贯等级和荣和/自摸支付计算
- AI 对手牌效决策
- AI 推荐前三候选牌、向听数和进张分析
- 响应式桌面与移动端界面

当前版本聚焦门清对局。吃、碰、明杠、暗杠、加杠和连庄尚未加入；计分引擎已经预留抢杠、岭上开花、三杠子、四杠子、赤宝牌与三麻北宝牌接口，待副露/杠操作系统启用。

## 已支持役种

- 一番：立直、一发、门前清自摸和、断幺九、平和、一杯口、役牌、海底摸月、河底捞鱼
- 二至六番：两立直、三色同顺、一气通贯、对对和、三暗刻、小三元、混老头、七对子、混全带幺九、纯全带幺九、二杯口、混一色、清一色
- 役满：天和、地和、国士无双、大三元、四暗刻、字一色、绿一色、清老头、小四喜、大四喜、九莲宝灯
- 双倍役满：国士无双十三面、四暗刻单骑、纯正九莲宝灯、大四喜

## 运行

项目没有生产依赖。使用任意静态服务器打开：

```bash
npx serve .
```

也可以使用 VS Code Live Server 等静态服务器。由于使用 ES Modules，不建议直接双击 `index.html` 以 `file://` 打开。

## 测试

需要 Node.js 20 或更高版本：

```bash
npm test
```
