# 雀研所 · game_mahjong

一款浏览器内运行的单机日麻训练小游戏。它把真实摸切对局和 AI 牌效分析结合起来，让玩家在每次决策时看到向听数、有效牌种类和剩余进张枚数。

## 当前功能

- 四人麻将和三人麻将牌组
- 普通模式与 AI 教练模式
- 真实牌山、摸牌、弃牌及河牌
- 标准四面子一雀头与七对子和牌判定
- 自摸、荣和、立直、荒牌流局
- AI 对手牌效决策
- AI 推荐前三候选牌、向听数和进张分析
- 响应式桌面与移动端界面

这是一个聚焦核心循环的 MVP。副露、役种判定、完整番符计分、连庄和南入规则尚未加入。

## 运行

项目没有生产依赖。使用任意静态服务器打开：

```bash
npx serve .
```

也可以使用 VS Code Live Server 等静态服务器。由于使用 ES Modules，不建议直接双击 `index.html` 以 `file://` 打开。

## 测试

需要 Node.js 20 或更高版本：

```bash
npm test
```
