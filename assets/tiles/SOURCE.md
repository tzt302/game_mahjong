# Standard riichi tile artwork

The SVG tile faces in `regular/` come from
[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles).

The upstream project states that all assets are in the public domain. The
original license text is preserved in `LICENSE.md`. Files are used without
visual modification so the game matches conventional Japanese riichi tiles.
